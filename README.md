# guida-beamng-g923
# Guida e Configurazioni BeamNG & Logitech G923

Questo progetto open source raccoglie appunti, configurazioni consigliate e risorse utili per migliorare l'esperienza di guida su BeamNG.drive con il volante Logitech G923.

## Funzionalità principali
- Impostazioni Force Feedback (FFB) ottimizzate.
- Configurazione LED contagiri (RPM).
- Mappatura consigliata dei tasti sul volante.

## Come contribuire
Chiunque può proporre miglioramenti alle configurazioni aprendo una Issue o una Pull Request.
